# Mimesis Escape QTE

Самостоятельное освобождение из захвата Mimesis — с помощью нескольких нажатий клавиши.

Неофициальный мод для **MIMESIS на Windows**. Когда монстр хватает игрока, появляется подсказка с прогрессом и оставшимся временем. Успей выполнить QTE, чтобы вырваться.

> **Тестовая версия 0.2.2 для MIMESIS 0.4.2, Steam build 26558062.** На другой сборке игры мод отключается до выпуска совместимого обновления.

## Скачать

**[Скачать готовый мод →](https://github.com/geologos07/MimesisEscape/releases)**

В разделе Releases выбирай полный ZIP для Windows. Всё необходимое уже включено в пакет — отдельно устанавливать библиотеки или инструменты разработки не нужно.

## Что умеет мод

- Позволяет попытаться вырваться из удушающего захвата Mimesis.
- Показывает клавишу, счётчик нажатий и оставшееся время.
- Позволяет выбрать удобную клавишу прямо в настройках игры.
- Засчитывает отдельные нажатия: удерживать кнопку недостаточно.
- При неудаче оставляет обычное поведение захвата, без дополнительного штрафа.

Сейчас поддерживается только этот захват Mimesis. Другие монстры и виды захватов пока не поддерживаются.

## Как установить

1. Полностью закрой игру.
2. Скачай готовый ZIP из раздела **Releases**.
3. В Steam открой **MIMESIS → Управление → Просмотреть локальные файлы**.
4. Распакуй содержимое ZIP в папку с `MIMESIS.exe`.
5. Запусти игру обычным способом через Steam.

Файл `version.dll` должен оказаться рядом с `MIMESIS.exe`, а `MimesisEscape.dll` — в папке `Mods`. Отдельно запускать файлы из архива не нужно.

Для установки нужен готовый пакет из Releases. Архив **Source code**, который GitHub предлагает автоматически, содержит исходники.

## Как пользоваться

По умолчанию нужно **пять раз нажать и отпустить F6 за время до трёх секунд**.

Клавиша меняется здесь:

**Настройки → Управление → Освобождение (QTE)**

Название пункта мода — «Освобождение (QTE)»; оно отображается по-русски.

Нажми поле клавиатуры и выбери свободную клавишу. Настройка сохраняется и применяется сразу. Если клавиша уже занята другим действием, выбери другую.

Во время меню и чата нажатия не засчитываются, а время продолжает идти. Переключение в другое окно отменяет попытку. При задержке сети доступное время может быть короче.

## Как играть с друзьями

**Одинаковая версия мода нужна у хоста и у каждого игрока, который хочет пользоваться QTE.** Хост — тот, кто создал комнату.

Игроки без мода могут участвовать в сессии, но QTE у них не появится. Если мод есть только у клиента, а у хоста его нет, освобождение через QTE недоступно.

## Что уже проверено

Версия 0.2.2 проверена запуском на MIMESIS 0.4.2, build 26558062: мод загружается, строка «Освобождение (QTE)» находится в общем списке управления, поле открывает выбор клавиши, Esc отменяет выбор. Освобождение игрока-хоста подтверждено на предыдущей версии мода. Реальный захват на новой версии и полный тест с отдельными хостом и клиентом пока не завершены.

Поэтому версия помечена как тестовая. Проверяйте её в приватной комнате. Совместимость со всеми другими модами не проверялась.

Мод не возвращает потерянное здоровье, не убирает накопленное заражение и не увеличивает время захвата.

## Как удалить

Закрой игру и удали файл:

`Mods/MimesisEscape.dll`

Сохранённая клавиша останется на случай повторной установки.
