# Mimesis Escape QTE

키를 여러 번 눌러 Mimesis, Mama Monkey, Quokka Glider의 붙잡기에서 스스로 탈출할 수 있습니다.

**Windows용 MIMESIS**의 비공식 모드입니다. 몬스터에게 붙잡히면 진행 상황과 남은 시간을 알려 주는 안내가 표시됩니다. 제한 시간 안에 QTE를 완료하면 탈출할 수 있습니다.

> **MIMESIS 0.4.2, Steam 빌드 26558062용 버전 0.2.4입니다.** 다른 게임 빌드에서는 호환 업데이트가 나올 때까지 모드가 비활성화됩니다.

## 다운로드

**[바로 설치할 수 있는 모드 다운로드 →](https://github.com/geologos07/MimesisEscape/releases)**

Releases에서 Windows용 전체 ZIP 패키지를 선택하세요. 필요한 구성 요소가 모두 포함되어 있어 라이브러리나 개발 도구를 따로 설치할 필요가 없습니다.

## 모드 기능

- Mimesis, Mama Monkey, Quokka Glider의 붙잡기에서 탈출을 시도할 수 있습니다.
- 사용할 키, 누른 횟수, 남은 시간을 표시합니다.
- 게임 설정에서 원하는 키를 선택할 수 있습니다.
- 키를 눌렀다 떼는 개별 입력만 계산합니다. 계속 누르고 있는 것만으로는 부족합니다.
- 실패하면 추가 불이익 없이 기존 붙잡기 동작이 계속됩니다.

다른 몬스터나 다른 종류의 붙잡기는 아직 지원하지 않습니다.

## 설치 방법

1. 게임을 완전히 종료하세요.
2. **Releases**에서 설치용 ZIP을 다운로드하세요.
3. Steam에서 **MIMESIS → 관리 → 로컬 파일 보기**를 여세요.
4. `MIMESIS.exe`가 있는 폴더에 ZIP 내용물을 압축 해제하세요.
5. 평소처럼 Steam에서 게임을 실행하세요.

`version.dll`은 `MIMESIS.exe`와 같은 폴더에, `MimesisEscape.dll`은 `Mods` 폴더에 있어야 합니다. 압축 파일 안의 파일을 따로 실행할 필요는 없습니다.

설치할 때는 Releases의 설치용 패키지를 사용하세요. GitHub가 자동으로 제공하는 **Source code** 압축 파일에는 소스 코드가 들어 있습니다.

## 사용 방법

기본 설정에서는 **최대 3초 안에 F6를 다섯 번 눌렀다 떼야 합니다**.

키는 다음 위치에서 변경할 수 있습니다.

**설정 → 컨트롤 → 탈출 (QTE)**

모드는 게임에서 선택한 언어를 자동으로 사용합니다. 게임의 18개 언어를 지원합니다.

키보드 입력 칸을 클릭한 다음 사용하지 않는 키를 선택하세요. 설정은 저장되며 즉시 적용됩니다. 이미 다른 동작에 지정된 키라면 다른 키를 선택하세요.

메뉴나 채팅이 열려 있는 동안에는 입력이 계산되지 않지만 시간은 계속 흐릅니다. 다른 창으로 전환하면 시도가 취소됩니다. 네트워크 지연으로 입력할 수 있는 시간이 줄어들 수 있습니다.

## 친구와 함께 플레이하기

**호스트와 QTE를 사용하려는 모든 플레이어에게 같은 버전의 모드가 필요합니다.** 호스트는 방을 만든 사람입니다.

모드가 없는 플레이어도 세션에 참여할 수 있지만 QTE는 표시되지 않습니다. 클라이언트에게만 모드가 있고 호스트에게는 없으면 QTE로 탈출할 수 없습니다.

## 확인 사항

MIMESIS 0.4.2, 빌드 26558062에서 버전 0.2.4를 실행했습니다. 사용자가 Mama Monkey와 Quokka Glider에게서 탈출하는 데 성공했다고 확인했으며, Mimesis에게서 탈출한 사례도 이전에 확인했습니다. 자동 검사 79개를 통과했습니다.

이 모드는 잃은 체력을 회복하거나 누적된 오염도를 없애지 않으며, 붙잡기 시간을 늘리지도 않습니다.

## 삭제 방법

게임을 종료한 뒤 다음 파일을 삭제하세요.

`Mods/MimesisEscape.dll`

다시 설치할 때 사용할 수 있도록 저장된 키 설정은 유지됩니다.
