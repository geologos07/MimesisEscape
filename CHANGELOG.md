# Changelog

Общая история проекта: игровой код, интерфейс, сборка, безопасность и документация. Со следующей версии после 0.2.1 файл включается в каждый выпускаемый пакет. Перед выпуском изменения из Unreleased переносятся в запись точной версии.

## [Unreleased]

## [0.2.4] - 2026-11-14

- Добавлено освобождение из захватов Mama Monkey и Quokka Glider для хоста и подключённых игроков с модом.
- Для обратного захвата Quokka используется штатное освобождение с проверкой привязки игрока и монстра на стороне хоста.
- Сетевая проверка учитывает длительные захваты и по-прежнему ограничивает время настройки QTE.

## [0.2.3] - 2026-11-14

- Добавлены переводы всех строк QTE для 18 языков игры с автоматическим выбором по текущим настройкам.
- Настройки и подсказка освобождения используют игровую обработку направления и формы арабского текста.
- Добавлены проверки полноты переводов, английского fallback и соответствия языкам установленной игры.


## [0.2.2] - 2026-11-14

- Добавлена поддержка основной сборки MIMESIS Steam build 26558062; обновлены проверенные хеши игровых файлов и MVID.
- Повторно проверены методы захвата, штатного освобождения, сетевой отправитель и входные проверки запросов QTE.
- Проверка сборки теперь сверяет все четыре хеша из мода и Steam build установленной игры перед выпуском.
- В установочный ZIP включён CHANGELOG.md; обновлены инструкция и описание GitHub-релиза.

- Подготовлен простой публичный README и макет отдельного GitHub-репозитория; несовместимость 0.2.1 с установленной обновлённой сборкой отмечена явно.

- Все файлы и инструменты мода изолированы в mods/MimesisEscape, готовые пакеты и история перенесены в releases; сборка не использует папки других модов.

- Закреплён запрос разрешения перед каждым новым игровым тестом и запись отказов.
- Аудит безопасности вынесен в обязательную проверку до компиляции и упаковки, независимо от игрового теста.
- Подготовлено обязательное включение changelog с записью версии в будущие пакеты; правила распространены на весь проект и будущие каналы Git/Steam Community.

## [0.2.1] - 2026-11-05

- Усилены проверки путей и ZIP; установка использует проверенный архив вместо старого staging.
- Добавлены ограничения формата, размера и частоты запросов QTE, явный криптографический генератор одноразовых разрешений.
- Убран вывод введённых значений из ошибок конфига; добавлен поиск секретов и отчёт аудита.

## [0.2.0] - 2026-11-05

- Подготовлен автономный Windows x64 ZIP с загрузчиком и компонентами Mono для установки копированием.
- Реализован клиентский QTE с проверкой и штатным освобождением на хосте.

## [0.1.2] - 2026-11-05

- Строка QTE перенесена в общий список управления; подсказка использует шрифт и цвет игрового HUD.

## [0.1.1] - 2026-11-05

- Добавлен выбор и сохранение клавиши QTE через игровые настройки.

## [0.1.0] - 2026-11-05

- Реализован QTE освобождения локального хоста из одного захвата Mimesis 30001.
