# Changelog

История изменений Mimesis Escape QTE.

## [0.2.1] - 2026-11-05

- Усилены проверки путей и ZIP; установка использует проверенный архив вместо старого staging.
- Добавлены ограничения формата, размера и частоты запросов QTE, явный криптографический генератор одноразовых разрешений.
- Убран вывод введённых значений из ошибок конфига; добавлен поиск секретов и отчёт аудита.

## [0.2.0] - 2026-11-05

- Подготовлен автономный Windows x64 ZIP с загрузчиком и компонентами Mono для установки копированием.
- Реализован клиентский QTE с проверкой и штатным освобождением на хосте. Реальный сетевой захват ещё ожидает проверки.

## [0.1.2] - 2026-11-05

- Строка QTE перенесена в общий список управления; подсказка использует шрифт и цвет игрового HUD.

## [0.1.1] - 2026-11-05

- Добавлен выбор и сохранение клавиши QTE через игровые настройки.

## [0.1.0] - 2026-11-05

- Реализован QTE освобождения локального хоста из одного захвата Mimesis 30001.
